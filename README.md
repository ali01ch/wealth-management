# دارایی من — مدیریت طلا، نقره و دلار

وب‌اپ موبایل‌فرست و کاملاً سمت‌کلاینت برای پیگیری موجودی طلای ۱۸ عیار، نقره و دلار با قیمت روز بازار ایران، محاسبه ارزش پرتفوی و فاصله تا اهداف مالی (مثل خرید خانه).

**ریپو:** [github.com/ali01ch/wealth-management](https://github.com/ali01ch/wealth-management) (خصوصی)

> برای GitHub Pages روی پلن رایگان، ریپو باید عمومی باشد. ورک‌فلو deploy در `.github/workflows/deploy-pages.yml` آماده است؛ بعد از public کردن، در Settings → Pages منبع را روی GitHub Actions بگذارید.

## امکانات

- ثبت خریدها با قیمت و تاریخ
- دریافت خودکار قیمت روز (دلار آزاد، طلا ۱۸ عیار، نقره)
- نمایش ارزش لحظه‌ای و سود/زیان
- تعریف هدف (مثلاً قیمت خانه) و محاسبه:
  - باقی‌مانده به تومان
  - معادل گرم طلا / گرم نقره / دلار لازم
  - تخمین زمان در صورت وارد کردن پس‌انداز ماهانه
- تحلیل انس جهانی: ارزش منصفانهٔ طلای ۱۸ عیار از انس × دلار و سیگنال «بخر / نخر»
- ذخیره محلی در مرورگر + خروجی/واردات JSON
- قابل افزودن به صفحهٔ اصلی گوشی (PWA ساده)

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس محلی را روی گوشی (همان شبکه) یا مرورگر دسکتاپ باز کنید.

ساخت نسخهٔ استاتیک:

```bash
npm run build
npm run preview
```

خروجی در پوشهٔ `dist` است و برای GitHub Pages مناسب است.

## منبع قیمت

- [Iran Market Data](https://iran-market.github.io/) — دلار آزاد و طلا ۱۸ عیار (و در صورت موجود بودن نقره)
- در صورت نبود نقره: [GTA Silver](https://gtasilver.com/silver-price) به‌عنوان پشتیبان

قیمت‌ها تقریبی بازار آزاد هستند و مرجع معامله رسمی نیستند.

## حریم خصوصی

همهٔ داده‌های دارایی فقط در `localStorage` همان مرورگر ذخیره می‌شوند و به سروری ارسال نمی‌شوند.
